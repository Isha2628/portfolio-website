# Isha Kumari | Frontend Developer Portfolio

A fully responsive personal portfolio website built as part of the **Web Development Internship** at **Codomax Digital Solutions**. This project showcases my skills, projects, education, and experience as an aspiring Frontend/Full Stack Developer.

🌐 **Live Site:** [https://isha2628.github.io/portfolio-website/](https://isha2628.github.io/portfolio-website/)
💻 **Repository:** [https://github.com/Isha2628/portfolio-website](https://github.com/Isha2628/portfolio-website)

---

## 📖 About the Project

This portfolio website was built from scratch over a 14-day structured internship program, progressing from basic HTML structure to a fully styled, responsive, and interactive website deployed live using GitHub Pages.

The site includes a terminal-themed hero section, smooth scroll navigation, animated sections, a validated contact form, and a fully responsive layout optimized for mobile, tablet, and desktop devices.

---

## ✨ Features

- 🖥️ Terminal-style animated hero section with typewriter effect
- 🧭 Smooth scrolling navigation with active link highlighting
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🎨 Custom hover effects, transitions, and scroll-reveal animations
- 🧩 Projects section with individual project cards
- 📝 Contact form with client-side validation
- ⬆️ Scroll-to-top button
- 🔗 Social media integration (GitHub, LinkedIn, Email)

## 🚀 Getting Started (Run Locally)

1. Clone the repository
   ```bash
   git clone https://github.com/Isha2628/portfolio-website.git
   ```
2. Navigate into the project folder
   ```bash
   cd portfolio-website
   ```
3. Open `index.html` in your browser
   - Or use the **Live Server** extension in VS Code for auto-reload
